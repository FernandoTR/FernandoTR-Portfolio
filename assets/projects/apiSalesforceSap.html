Integración de Salesforce y SAP Business One

API REST segura, desarrollada en .NET 8, que conecta Salesforce con SAP Business One. Automatiza la creación de órdenes de venta y sincroniza datos entre ambos sistemas.

Proyecto privado · Desarrollo backend

Documentación Swagger de la API; está abierta la operación para generar un token.

Funciones principales

Órdenes de venta

La API crea en SAP B1 las órdenes generadas en Salesforce y reduce la captura manual.

Consultas comerciales

La integración consulta información de clientes, productos, inventario y precios en los sistemas conectados.

Autenticación y validación

La API autentica cada solicitud con un token, valida los datos recibidos y controla el acceso a endpoints críticos.

Contratos de API definidos

Especifican cómo intercambiar datos y facilitan la integración, las pruebas y el mantenimiento.

Detalles del proyecto

  • Descripción

Cómo está construida la API

La API separa las rutas REST, la validación y conversión de datos, y la comunicación con Salesforce y SAP. Esta organización facilita entender y mantener cada parte de la integración.

Salesforce

Envía solicitudes comerciales y datos de clientes, productos y órdenes.

API .NET

Autentica las solicitudes, valida y adapta los datos, y coordina cada operación.

SAP B1

Recibe órdenes de venta y permite consultar la información operativa del ERP.

SAP HANA

Proporciona los datos de inventario y las listas de precios que consulta la integración.

Endpoints destacados

Método Ruta Función
  • POST /api/Token

    Genera un token para autenticar las solicitudes a la API.

  • POST /api/SalesforceOrder

    Crea en SAP B1 una orden de venta con la información comercial recibida de Salesforce.

  • GET /api/SalesforceStock/Stock

    Consulta las existencias de un artículo en cada almacén de SAP B1.

  • POST /api/SalesforceBusinessPartner/Create

    Crea en SAP B1 un cliente con la información recibida de Salesforce.

  • GET /api/SAPPriceList

    Devuelve las listas de precios de SAP disponibles para los procesos comerciales.

  • PATCH /api/SAPProduct/{itemCode}

    Actualiza en Salesforce el producto identificado por su código.

Seguridad

Autenticación de solicitudes y validación de datos.

Cómo se protege

  • Autenticación por token

    La API admite autenticación mediante token y flujos OAuth 2.0.

  • Validación de datos

    La API valida los datos recibidos y los convierte al formato que requiere cada sistema.

  • Pruebas con Postman

    Los flujos comerciales se probaron en Postman para detectar errores en operaciones críticas.
