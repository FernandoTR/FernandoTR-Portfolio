Portal de Viáticos

Portal web para gestionar solicitudes, comprobaciones y autorizaciones de viáticos sin dar acceso directo a SAP Business One.

Proyecto privado · Desarrollo Full Stack .NET

Qué permite hacer el portal

Solicitud y comprobación

Permite registrar solicitudes y adjuntar archivos XML, PDF e imágenes para comprobar gastos. Aplica validaciones fiscales al cargar el XML.

Flujo por roles

Separa los permisos de empleados, autorizadores y personal administrativo.

Integración financiera

Sincroniza facturas, pagos, reembolsos y reintegros con SAP Business One.

Trazabilidad operativa

Permite consultar el historial de solicitudes, estados, documentos y validaciones de cada gasto.

Detalles del proyecto

  • Problema y solución

    La gestión de viáticos dependía de procesos manuales, documentos dispersos y acceso directo a SAP Business One. El portal centraliza solicitudes, comprobaciones y autorizaciones, aplica validaciones fiscales y sincroniza operaciones con SAP para mantener la consistencia contable. Así, los usuarios finales pueden trabajar sin licencias ni acceso directo al ERP.

Arquitectura e integración

El portal combina ASP.NET MVC y C# con almacenamiento en SQL Server. Se despliega en IIS y utiliza DI API para integrar las operaciones financieras con SAP Business One.

  1. Web MVC

    Formularios, validaciones de entrada y carga de documentos con JavaScript y jQuery.

  2. Negocio

    Reglas de autorización, comprobación, validación fiscal y seguimiento de estados.

  3. Integración

    Conexión con SAP Business One mediante DI API para documentos, pagos, reembolsos y reintegros contables.

  4. Datos / IIS

    Almacenamiento en SQL Server, gestión de comprobantes y despliegue en IIS sobre Windows.

Control operativo y trazabilidad

El área administrativa puede dar seguimiento a los gastos desde el portal.

  • Validaciones y seguimiento

    El portal reúne comprobantes, validaciones fiscales, permisos por rol e historial de estados para dar seguimiento a cada solicitud, sin requerir que los usuarios finales entren a SAP Business One.
