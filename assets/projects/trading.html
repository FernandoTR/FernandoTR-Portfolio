Trading Book

Plataforma web para centralizar operaciones de trading cripto, medir performance, evaluar setups y convertir ejecuciones reales en información accionable.

.NET 10

ASP.NET Core MVC

4 capas

Clean Architecture

2FA

Identity + Authenticator

Database-first analytics

Trading Book nace como una herramienta para analizar la calidad operativa de cada trade. El sistema registra operaciones, cuentas, triggers, escenarios, figuras, direcciones y temporalidades, y los transforma en indicadores para detectar patrones, medir consistencia y mejorar la toma de decisiones.

Tecnologías:
.NET 10 ASP.NET Core MVC Entity Framework Core 10 SQL Server Clean Architecture Metronic 9 Tailwind CSS Chart.js DataTables 2.x ASP.NET Core Identity MailKit
Contexto y solución

Trading Book convierte el registro de operaciones cripto en una base analítica para medir consistencia, comparar setups y detectar patrones. La solución centraliza trades, cuentas, catálogos y dashboards en una aplicación .NET con arquitectura limpia y foco en datos accionables.

Capacidades principales
01
Trading Score Engine

Evalúa cada operación por ubicación, tendencia, confirmación y zonas pivote.

02
Análisis multidimensional

Lecturas por trigger, escenario, figura, dirección, temporalidad y día.

03
Dashboard y exploración

Visualizaciones con Chart.js y tablas DataTables para revisar performance.

04
Gestión operativa

Cuentas, balances, catálogos, actividad de usuario y módulos administrativos.

Arquitectura

El proyecto sigue Clean Architecture con dependencias unidireccionales y separación clara entre presentación, lógica de aplicación, dominio e infraestructura.

Web

Controladores MVC, vistas Razor, middlewares, helpers y assets estáticos.

Application

Servicios de negocio, DTOs, contratos, modelos de resultado y recursos localizados.

Domain

Entidades, constantes y enumeraciones que representan el núcleo del negocio.

Infrastructure

Persistencia, repositorios, Identity, email y logging de actividad.

Seguridad y hardening
Autenticación robusta y configuración segura

Identity con 2FA, confirmación de email, recuperación de contraseña anti-enumeración, rate limiting, cookies HTTPS y credenciales externalizadas.
